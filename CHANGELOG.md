# Changelog

## 1.0.1 (2026-10-15)

First public release.

- Toolbar button on the message toolbar, with **Check sender** and
  **Report sender as spam** (with confirmation).
- Settings page for the IsEmailSpam API key; the saved key is shown
  masked.
- Results survive closing and reopening the popup for the current
  session.
- Clear error messages for missing keys, rejected keys, IP restrictions,
  rate limits, timeouts and unexpected responses.
