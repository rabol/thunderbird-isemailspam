IsEmailSpam settings

Get an API key from isemailspam.com. Saving doesn't contact the service; the key is checked the first time you use Check or Report.

Website access

IsEmailSpam needs permission to contact isemailspam.com.

Privacy

  • When you choose Check sender or Report sender as spam, the sender's email address (from the From header) and your API key are sent to isemailspam.com. Nothing is sent when you only open the menu.
  • No message content, subject, recipients or attachments leave Thunderbird.
  • Your API key is kept in this add-on's local storage in your Thunderbird profile. That storage isn't an encrypted password vault, so anyone with access to your profile can read it.
  • Check and report history isn't saved. Results are kept only until Thunderbird or the add-on restarts.
